# Реклама: план інтеграції

> **Стоп-сигнал.** Політика конфіденційності всіма 43 мовами
> прямо каже, що реклами в застосунку немає **і не буде**. Якщо колись вирішиш
> її підключити, спершу треба прибрати той розділ — інакше застосунок буде
> суперечити власному юридичному документу, а це гірше за саму рекламу.
> Розділ доданий за прямим рішенням Ігоря; це компроміс, який він обрав свідомо.
> Плюс, як і раніше, доведеться змінити відповіді в Data Safety.

Версія 1.0 виходить **без реклами**. Цей документ фіксує, де саме вона з'явиться
і як її під'єднати, щоб рішення про розміщення було прийняте разом із дизайном
макета, а не приліплене згори через півроку.

---

## Головне технічне обмеження

Це треба знати до того, як щось планувати.

Додаток — це вебсторінка, загорнута в Android-застосунок (Capacitor). Банер AdMob
**не є частиною цієї сторінки**. Це окреме нативне вікно Android, яке система
малює **поверх** вебсторінки. З цього випливає жорстке обмеження:

> Банер можна причепити **тільки до верхнього або нижнього краю екрана**.
> Вставити його «між картками» посеред сторінки технічно неможливо.

Формат, який дозволив би справжню вбудовану рекламу-картку, називається
**AdMob Native Advanced**. Плагін `@capacitor-community/admob` його **не
підтримує** — тільки банери, повноекранні (interstitial) та за винагороду
(rewarded). Щоб отримати Native Advanced, довелося б писати власний нативний
плагін на Java. Це велика окрема робота, не для версії 1.1.

Варіант «показати Google AdSense прямо у вебсторінці» **заборонений правилами
AdSense** — реклама AdSense не може показуватись усередині WebView застосунку.
За це блокують акаунт.

Отже реалістичних варіантів рівно два, і обидва вже враховані в макеті.

---

## Слот A — нижня полиця (основний)

**Що це.** Адаптивний банер AdMob (`ADAPTIVE_BANNER`, висота 50–60 px залежно
від екрана), закріплений унизу.

**Чому це не дратує.** Ключова відмінність від того, як це роблять інші:
додаток **сам резервує під банер місце**. У `src/index.css` є змінна:

```css
:root { --ad-slot-h: 0px; }
```

і `body` має `padding-bottom: calc(env(safe-area-inset-bottom) + var(--ad-slot-h))`.
Коли реклама вмикається, `--ad-slot-h` виставляється в реальну висоту банера — і
контент просто стає на стільки коротшим. Банер **нічого не накриває**, не
з'їжджає на кнопки й не з'являється раптово поверх тексту. Він стоїть у своїй
полиці з тим самим фоном і рамкою, що й картки додатка.

Саме там раніше була неробоча нижня навігація — місце вже звільнене.

**Точка підключення:** `<AdSlot placement="bottom-anchor" />` у
`src/components/Layout.tsx`.

## Слот B — картка в стрічці контенту

**Що це.** Звичайний `div` усередині сторінки, між «Структурою інвестицій» і
«Таблицею прогнозу», стилізований точно як інші картки (`.card`: той самий фон,
радіус, рамка, тінь).

**Чим наповнювати.** Це **не AdMob** — плагін тут не потрібен. Підходить для:
- власного промо (інші твої додатки, посилання на вебверсію);
- партнерських/афілійованих посилань на брокерів, банки, курси;
- статичного банера від прямого рекламодавця.

Виглядає як частина додатка, бо технічно нею і є.

**Точка підключення:** `<AdSlot placement="inline-card" />` у `src/App.tsx`.

## Чого не робимо ніколи

- **Interstitial** — реклама на весь екран між діями. Саме те, що дратує тебе в
  інших додатках.
- **Rewarded** — відео за винагороду. Немає що давати у винагороду.
- Банер, що накриває контент або кнопки.
- Автовідтворення відео зі звуком.

## Як під'єднати AdMob (коли дійде черга)

### 1. Створити акаунт і рекламний блок

1. Зареєструватись на [admob.google.com](https://admob.google.com) (безкоштовно).
2. Додати застосунок → Android → `com.ihorfinance.compoundcalc`.
3. Отримати **App ID** — виглядає як `ca-app-pub-XXXXXXXXXXXXXXXX~YYYYYYYYYY`
   (з тильдою).
4. Створити рекламний блок типу **Banner** → отримати **Ad Unit ID** —
   `ca-app-pub-XXXXXXXXXXXXXXXX/ZZZZZZZZZZ` (зі скісною рискою).

### 2. Встановити плагін

```bash
npm install @capacitor-community/admob
npx cap sync android
```

### 3. Прописати App ID в Android

У `android/app/src/main/AndroidManifest.xml`, усередині `<application>`:

```xml
<meta-data
    android:name="com.google.android.gms.ads.APPLICATION_ID"
    android:value="ca-app-pub-XXXXXXXXXXXXXXXX~YYYYYYYYYY"/>
```

Без цього рядка застосунок **впаде одразу після запуску** — це найчастіша
помилка при першому підключенні AdMob.

### 4. Увімкнути слот у коді

У `src/components/AdSlot.tsx` замінити `const adsEnabled = false` на `true` і
дописати ініціалізацію (приблизно так):

```ts
import { AdMob, BannerAdSize, BannerAdPosition } from '@capacitor-community/admob';

await AdMob.initialize();

await AdMob.showBanner({
  adId: 'ca-app-pub-XXXXXXXXXXXXXXXX/ZZZZZZZZZZ',
  adSize: BannerAdSize.ADAPTIVE_BANNER,
  position: BannerAdPosition.BOTTOM_CENTER,
  margin: 0,
});

// Головне: віддати вебсторінці реальну висоту банера,
// щоб вона зарезервувала під нього місце.
AdMob.addListener('bannerAdSizeChanged', ({ height }) => {
  document.documentElement.style.setProperty('--ad-slot-h', `${height}px`);
});
```

### 5. Згода користувачів у ЄС (обов'язково)

Для показу персоналізованої реклами в Європі Google вимагає форму згоди
(**UMP — User Messaging Platform**). Без неї покази в ЄС будуть заблоковані:

```ts
const consent = await AdMob.requestConsentInfo();
if (consent.isConsentFormAvailable && consent.status === 'REQUIRED') {
  await AdMob.showConsentForm();
}
```

Форму треба спершу створити в кабінеті AdMob: *Privacy & messaging → GDPR*.

### 6. Оновити юридичну частину

Це **обов'язково**, інакше застосунок знімуть з публікації:

- **Google Play → Data safety.** Змінити з «дані не збираються» на:
  збирається *Device or other IDs* (рекламний ідентифікатор), мета —
  *Advertising or marketing*, передається третій стороні.
- **Політика конфіденційності** (`src/pages/PrivacyPolicy.tsx`) — додати розділ
  про AdMob, рекламний ідентифікатор і посилання на політику Google.
- **Віковий рейтинг** — перепройти анкету, вказавши наявність реклами.

### 7. Обов'язково протестувати на тестових ID

Поки не пройшов перевірку — використовуй **тестовий** блок Google, інакше
акаунт AdMob заблокують за накрутку показів власною рекламою:

```
Тестовий банер Android: ca-app-pub-3940256099942544/6300978111
```

## Порядок дій, коли будеш готовий

1. Випустити 1.0 **без реклами**, зібрати перших користувачів і відгуки.
   Перший реліз без реклами проходить перевірку Play помітно простіше.
2. Наповнити **слот B** власним промо — безкоштовно, без плагінів, без
   юридичних змін.
3. Тільки коли буде відчутний трафік — вмикати **слот A** з AdMob. При малій
   аудиторії дохід від банера рахується в центах, а робота з відповідністю
   правилам однакова.
