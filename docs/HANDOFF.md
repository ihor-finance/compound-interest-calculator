## Що це

Калькулятор складних відсотків для Android і вебу. Головна ідея: інші
калькулятори показують велике номінальне число, цей показує, **що на нього
справді можна буде купити** — після податків та інфляції.

- React 19 + Vite 8 + TypeScript 6 + Capacitor 8
- Package: `com.ihorfinance.compoundcalc` — **змінити після публікації неможливо**
- 43 мови, повністю: інтерфейс, методологія, юридичні сторінки, тексти для магазину
- Безкоштовний, без реклами, без покупок, працює офлайн, нічого не збирає

## Генератори ресурсів

```bash
npm run assets:icons        # іконки Android з public/web-app-manifest-512x512.png
npm run assets:frames -- --locales en,uk    # картки для Play
npm run assets:screenshots -- --locales en  # сирі знімки застосунку (діагностика)
```

Картки й знімки **не в git** — 43 мови × 7 карток це ~130 МБ, і все
відтворюється однією командою. У репозиторії рецепт, не результат. Файли лежать
на диску в `docs/store-assets/play-frames/`.

Генератори працюють через **вже встановлений Chrome по DevTools-протоколу**.
Нічого не завантажується: у браузера вже є шрифти, перенесення рядків і напрям
справа-наліво для всіх 43 мов, чого немає в жодного SVG-рендерера.

## Ключове рішення про картки

Вміст телефона на картках **намальовано**, а не зменшено зі знімка екрана: у
зменшеному знімку текст має висоту близько шести пікселів.

Але намальоване ≠ вигадане. Кожен підпис береться з файлів перекладу
застосунку, кожне число — з його ж модуля розрахунку. Аудит проти вихідного
коду прибрав **сім елементів**, яких у застосунку немає: смужку пропорцій,
заштриховану смугу під лініями графіка, крапки-маркери (у застосунку
`pointRadius: 0`), картку-підсумок над графіком, колонку відсотків у легенді
донату, пігулки з кодами мов і формулу з готовим числом на методології.

**Правило: якщо чогось немає в компоненті — на картці цього бути не повинно.**
Play вимагає, щоб скріншоти показували справжній застосунок.

## Що зроблено за цю сесію

Іконка: гліф відділявся від плитки за яскравістю червоного каналу, а світла
смуга вгорі плитки має червоний 160 — тому потрапляла в шар гліфа. Звідси
серпанок і зсув униз. Тепер поділ за насиченістю (гліф ≤ 0,05, градієнт ≥ 0,35).

Мови: порядок за поширеністю у світі, англійська перша. Поточна мова не
піднімається нагору — вона підсвічена там, де стоїть.

Тексти для Play: 43 мови × (назва + короткий + повний опис + 7 підписів).

Юридичні сторінки: було 14 мов, стало 43. Винесені з компонентів у
`src/pages/legal-content/`. Названо **ФОП Ihor Pokhyton**, бо Redempsly — це
торгова назва, а не особа, і Play звіряє розробника з документами.

Дві помилки, знайдені попутно: політика заявляла про Google Analytics, якого в
застосунку немає (і це суперечило б декларації Data Safety); напрям тексту
перевірявся як `lang === 'ar'`, тому іврит лишався зліва направо.
