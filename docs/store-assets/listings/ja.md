## Full description (max 4000)

```
たいていの複利計算機は、大きくて安心できる数字を見せてくれます。このアプリが見せるのは、その数字で実際に何が買えるのかです。

最初の金額、いくらをどのくらいの頻度で積み立てるか、そして期待する利回りを入力してください。アプリは資産を1か月ずつ計算し、そこからインフレと税金を差し引きます。表示されるのは明日のお金ではなく、今日の価値に換算した金額です。

ほかと違うところ

• インフレ調整後の結果。25年後の予想額50万は、購買力としての50万ではありません。2つの数字は常に並べて表示されます。
• 利益への課税。毎年課税されるか、引き出し時に一度だけ課税されるかを選べます。長期になるほど、この差は多くの人が思うより大きくなります。
• 本当の利回り。中心に表示される利率は、実際の積立スケジュールから求めた正しい金額加重利回りです。すべてを初日に投資したことにする簡易計算ではありません。
• 楽観シナリオと悲観シナリオ。利回りの範囲を有効にすると、3つのシナリオを同時に計算します。
• すべての計算式を適用順に並べ、最後まで解いた例題を添えた「計算方法」ページ。どの数字も手計算で確認できます。

設定できること

• 初期投資額と運用期間（最長100年）
• 積立の頻度：毎日・毎週・毎月・四半期ごと・半年ごと・毎年
• 複利の頻度：毎日・毎月・四半期ごと・半年ごと・毎年
• 想定年利（任意で下限と上限も設定可能）
• インフレ率
• 税率（毎年課税、または引き出し時に課税）

得られるもの

• 明快な中心の数字：今日の購買力に換算した資産の価値
• 4つの要約カード：積立総額、名目額、税引後の額、税とインフレを差し引いた額
• 期間全体にわたって4本の線を比較する成長グラフ
• 最終金額の内訳：自分が入れたお金、増えた分、そして税金
• 年ごと・月ごとの完全な予測表。全画面に展開できます

邪魔をしない設計

• 完全無料。サブスクリプションもアプリ内課金もありません。
• 完全にオフラインで動作します。サーバーはなく、すべての計算は端末内で行われます。
• アカウント登録も、サインアップも、メールアドレスも不要です。
• データを一切収集しません。入力した内容は端末に保存され、外部に送信されることはありません。
• 43言語対応。数値の表記もそれぞれの言語の慣習に従います。
• ライトテーマとダークテーマ。
• スマートフォンとタブレットの縦向き・横向きに対応。

重要なお知らせ

このアプリは学習と資産計画のための道具です。入力された前提条件から数学的な結果を計算するものであり、市場の予測を行うものではなく、金融・投資・税務に関する助言でもありません。実際の運用成績は異なり、過去の実績は将来の結果を保証しません。税制は国によって異なります。金融上の判断を行う前に、資格のある専門家にご相談ください。
```
