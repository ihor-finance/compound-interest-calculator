## Full description (max 4000)

```
大多数复利计算器给你一个看着舒服的大数字。这个应用告诉你，那个数字实际上能买到什么。

输入初始金额、每次追加的金额和频率，以及你预期的收益率。应用会逐月推演你的资金，然后扣除通货膨胀和税费，让你看到的是今天的购买力，而不是明天的数字。

有什么不同

• 经过通胀调整的结果。25 年后预计的 500,000 并不等于 500,000 的购买力。两个数字始终并排显示。
• 收益税。可选择每年缴税，或在提取时一次性缴纳。在长周期里，两者的差距比大多数人预想的要大。
• 真实收益率。首要百分比是按资金加权计算的真实收益率，依据你实际的追加投入时间表得出，而不是假装所有资金在第一天就已投入的简化算法。
• 乐观与悲观情景。开启收益率区间，即可同时推演三种情景。
• 方法说明页列出每一个公式及其应用顺序，并附完整演算示例。每一个数字你都可以手工核对。

可以设置的内容

• 初始存入金额与投资期限，最长 100 年
• 定期追加：每日、每周、每月、每季度、每半年或每年
• 复利频率：每日、每月、每季度、每半年或每年
• 预期年收益率，可另设最低值与最高值
• 通货膨胀率
• 税率，按年征收或提取时征收

你会得到什么

• 一个清晰的核心数字：你的钱按今天的购买力值多少
• 四块汇总卡片：累计投入、名义价值、税后价值、税后并经通胀调整的价值
• 增长图表，在整个期间内对比全部四条曲线
• 最终金额的构成拆解：你投入的钱、增值部分和税费
• 完整的推演表格，按年或按月，可展开为全屏

不打扰你的设计

• 完全免费。没有订阅，没有应用内购买。
• 完全离线运行。没有服务器，所有计算都在你的设备上完成。
• 无需账号、无需注册、无需邮箱。
• 不收集任何数据。你输入的内容保存在手机本地，不会外传。
• 43 种语言，数字格式遵循各自的习惯。
• 浅色与深色主题。
• 为手机和平板设计，支持竖屏与横屏。

重要提示

本应用是教育与规划工具。它根据你输入的假设推演数学结果，并不预测市场，也不构成财务、投资或税务建议。实际收益会有差异，过往表现不代表未来结果，各国税制也各不相同。做出财务决策前，请咨询具备资质的专业人士。
```
