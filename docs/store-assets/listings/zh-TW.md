## Full description (max 4000)

```
大多數複利計算機給你一個看了很舒服的大數字。這個應用程式告訴你，那個數字實際上買得到什麼。

輸入期初金額、每次追加的金額與頻率，以及你預期的報酬率。應用程式會逐月推演你的資金，然後扣掉通貨膨脹與稅負，讓你看到的是今天的購買力，而不是明天的數字。

有什麼不一樣

• 經通膨調整的結果。25 年後預估的 500,000 並不等於 500,000 的購買力。兩個數字一律並排顯示。
• 獲利稅。可選擇每年繳稅，或在提領時一次繳清。期間拉長後，兩者的差距比多數人想像的還大。
• 實質報酬率。最上面那個百分比是以資金加權計算的實質報酬率，依據你實際的追加時間表得出，而不是假裝所有資金在第一天就投進去的簡化算法。
• 樂觀與悲觀情境。開啟報酬率區間，就能同時推演三種情境。
• 方法說明頁列出每一條公式與套用的順序，並附完整的演算範例。每一個數字你都可以手工核對。

可以設定的內容

• 期初投入金額與投資期間，最長 100 年
• 定期追加：每日、每週、每月、每季、每半年或每年
• 複利頻率：每日、每月、每季、每半年或每年
• 預期年報酬率，可另設最低值與最高值
• 通貨膨脹率
• 稅率，按年課徵或提領時課徵

你會得到什麼

• 一個清楚的核心數字：你的錢以今天的購買力值多少
• 四張摘要卡片：累計投入、名目價值、稅後價值、稅後並經通膨調整的價值
• 成長圖表，在整段期間內對照全部四條曲線
• 最終金額的組成拆解：你投入的錢、增值的部分與稅款
• 完整的推演表格，按年或按月，可展開成全螢幕

不打擾你的設計

• 完全免費。沒有訂閱，沒有應用程式內購買。
• 完全離線運作。沒有伺服器，所有計算都在你的裝置上完成。
• 不必帳號、不必註冊、不必電子郵件。
• 不蒐集任何資料。你輸入的內容留在手機本機，不會外傳。
• 44 種語言，數字格式各依自己的慣例。
• 淺色與深色主題。
• 為手機與平板設計，支援直向與橫向。

重要提醒

本應用程式是教育與規劃工具。它依你輸入的假設推演數學結果，並不預測市場，也不構成財務、投資或稅務建議。實際報酬會有落差，過去績效不代表未來結果，各國稅制也各不相同。做出財務決定前，請諮詢具備資格的專業人士。
```
