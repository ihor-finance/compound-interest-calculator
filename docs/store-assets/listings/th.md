## Full description (max 4000)

```
เครื่องคิดดอกเบี้ยทบต้นส่วนใหญ่แสดงตัวเลขใหญ่ ๆ ที่ทำให้สบายใจ แอปนี้แสดงว่าตัวเลขนั้นซื้ออะไรได้จริง

ใส่เงินตั้งต้น จำนวนและความถี่ที่คุณเติมเงิน และผลตอบแทนที่คาดไว้ แอปจะคำนวณเงินของคุณเดือนต่อเดือน แล้วหักเงินเฟ้อและภาษีออก เพื่อให้คุณเห็นผลลัพธ์เป็นเงินของวันนี้ ไม่ใช่ของวันหน้า

อะไรที่ต่างออกไป

• ผลลัพธ์ที่ปรับตามเงินเฟ้อแล้ว เงิน 500,000 ในอีก 25 ปี ไม่เท่ากับอำนาจซื้อ 500,000 ทั้งสองตัวเลขแสดงคู่กันเสมอ
• ภาษีจากกำไร เลือกเสียภาษีทุกปี หรือครั้งเดียวตอนถอน ในระยะยาวส่วนต่างมากกว่าที่คนส่วนใหญ่คิด
• อัตราผลตอบแทนที่แท้จริง เปอร์เซ็นต์หลักคือผลตอบแทนถ่วงน้ำหนักด้วยเงิน คำนวณจากตารางการฝากจริงของคุณ ไม่ใช่ทางลัดที่สมมติว่าเงินทั้งหมดลงไปตั้งแต่วันแรก
• กรณีดีที่สุดและแย่ที่สุด เปิดช่วงผลตอบแทน แล้วแอปจะคำนวณทั้งสามสถานการณ์พร้อมกัน
• หน้าระเบียบวิธีที่แสดงทุกสูตรตามลำดับการใช้งาน พร้อมตัวอย่างที่แก้จนจบ ตรวจสอบทุกตัวเลขด้วยมือได้

สิ่งที่ตั้งค่าได้

• เงินฝากเริ่มต้นและระยะเวลาลงทุน สูงสุด 100 ปี
• เงินฝากประจำ: รายวัน รายสัปดาห์ รายเดือน รายไตรมาส ทุกครึ่งปี หรือรายปี
• ความถี่ทบต้น: รายวัน รายเดือน รายไตรมาส ทุกครึ่งปี หรือรายปี
• ผลตอบแทนรายปีที่คาดไว้ พร้อมค่าต่ำสุดและสูงสุดเพิ่มเติม
• อัตราเงินเฟ้อ
• อัตราภาษี เก็บรายปีหรือตอนถอน

สิ่งที่คุณจะได้

• ตัวเลขหลักที่ชัดเจน: เงินของคุณมีค่าเท่าไรในอำนาจซื้อวันนี้
• การ์ดสรุปสี่ใบ: ยอดฝากรวม มูลค่าตามบัญชี มูลค่าหลังภาษี และมูลค่าหลังภาษีและเงินเฟ้อ
• กราฟการเติบโตที่เปรียบเทียบทั้งสี่เส้นตลอดระยะเวลา
• การแยกที่มาของยอดสุดท้าย: เงินของคุณ ส่วนที่งอกเงย และภาษี
• ตารางประมาณการเต็ม รายปีหรือรายเดือน เปิดเต็มจอได้

สร้างมาเพื่อไม่รบกวนคุณ

• ฟรีทั้งหมด ไม่มีการสมัครสมาชิก ไม่มีการซื้อในแอป
• ทำงานออฟไลน์เต็มรูปแบบ ไม่มีเซิร์ฟเวอร์ ทุกการคำนวณอยู่บนเครื่องของคุณ
• ไม่ต้องมีบัญชี ไม่ต้องสมัคร ไม่ต้องใช้อีเมล
• ไม่เก็บข้อมูลใด ๆ สิ่งที่คุณกรอกอยู่ในเครื่องและไม่ออกไปไหน
• 43 ภาษา พร้อมรูปแบบตัวเลขตามแต่ละภาษา
• ธีมสว่างและมืด
• ออกแบบสำหรับโทรศัพท์และแท็บเล็ต ทั้งแนวตั้งและแนวนอน

ข้อสำคัญ

แอปนี้เป็นเครื่องมือเพื่อการศึกษาและวางแผน คำนวณผลลัพธ์ทางคณิตศาสตร์จากสมมติฐานที่คุณกรอก ไม่ได้ทำนายตลาด และไม่ใช่คำแนะนำทางการเงิน การลงทุน หรือภาษี ผลตอบแทนจริงแตกต่างกันไป ผลงานในอดีตไม่รับประกันผลในอนาคต และกฎภาษีต่างกันในแต่ละประเทศ ควรปรึกษาผู้เชี่ยวชาญที่มีคุณสมบัติก่อนตัดสินใจทางการเงิน
```
